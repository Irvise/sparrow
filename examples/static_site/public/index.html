Served by Sparrow

Every file in this folder is served at its path, with its media type, an ETag and Last-Modified. Reload the page with the network tab open: unchanged files come back as 304 Not Modified.

The whole server is one route:

package Site_Files is new Sparrow.Http.Static.Folder (Root => "public");

Routers.Add (Routes, Get, "/*file", Site_Files.Handle'Access);

See also a folder with its own index, and try escaping the folder or a hidden file: both are 404.
